配置方案管理模块及“默认”样式重构需求

1. “默认”配置方案的写时复制（Copy-on-Write）与重置机制

  • 只读保护：原生【默认】配置为只读状态，不允许直接更改或覆盖。
  • 自动衍生新方案：当当前激活方案为【默认】时，用户触发任何可调节参数修改时：
    1. 系统自动创建一个独立的新方案，命名为【默认调整】（与【用户1】、【用户2】等并列）。
    2. 将本次所有的参数变更保存至【默认调整】中。
    3. 自动将当前激活状态切换至【默认调整】，底部 Bar 对应的选择按钮文本同步显示为“默认调整”。
  • 覆盖/重新生成逻辑：若当前激活方案为【默认调整】，当用户手动切换回原生【默认】配置并再次进行任何参数调整时，系统需自动删除已有/旧的【默认调整】配置文件，并重新生成一份新的基于当前【默认】修改后的【默认调整】进行保存。

2. 自定义方案（如【用户1】、【用户2】）的延迟创建与加载逻辑

  • 不存在时的默认渲染：当用户选择某个自定义方案（如【用户1】）时，若其对应的配置文件尚不存在，页面所有属性参数暂且按原生【默认】配置呈现。
  • 写时自动生成文件：在上述不存在配置文件的状态下，只要用户对任意属性进行了调整，系统立刻自动创建对应的配置文件（如生成 用户1.json），并将用户的调整写入该配置文件。
  • 已存在配置优先加载：当用户选择某个自定义方案（如【用户2】）时，若对应配置文件已存在，则直接加载并应用该配置文件中的设置，不再加载默认样式。

3. 原生【默认】方案各项样式属性的初始值设定

底部 Bar 选择原生【默认】按钮，对部分样式属性初始值调整如下：

1. 【行内代码】-【行内字号】调整成-2px，【行内边距】调整成1px。 2. 【代码块】-【显示行号】开关默认打开。 3. 【字体】-【文字排版】，文字大小默认是18px，文本行距默认是1.4。 4. 【版面】【版面宽度】在页面加载时自动计算，宽度为单行显示37个汉字的宽度，按照一个汉字等于2个英文字符，也就是74个英文字符。但是，后续可以自由调节【版面宽度】

4. 配置方案列表 UI 渲染与“打开本地目录”交互

  • 入口图标化：配置方案列表中，每一个配置方案项（包括【默认调整】、【用户1/2/3】等）右侧统一放置一个文件夹图标按钮（如 FolderOpen 风格）。
  • 悬浮与点击响应：
    • 鼠标悬浮在文件夹图标上时，弹出 Tooltip 提示：在文件管理器中打开配置目录。
    • 点击文件夹图标后，调用系统 API，直接在文件管理器中打开本地保存配置文件的根目录。
  • 集中管理：所有方案对应的配置文件均存储于同一个目录下。

5. 本地配置文件动态扫描与自动加载

  • 动态扫描解析：配置管理模块支持对本地配置文件目录的自动扫描。
  • 支持外部新增与编辑：允许用户直接在打开的本地配置目录下新增文件（如 JSON / YAML 格式）、直接修改已有文件内容或扩充不同的属性字段。配置文件的每一项可以有属性说明（也就是配置帮助以注释的形式和配置放在一起）
  • 自动更新列表：软件启动或发现该目录变更时，系统动态解析该目录下所有的合法配置文件，并自动将其渲染填充到 UI 方案列表中。当然【用户1/2/3】是默认就存在的不管文件存在与否。

6. 配置文件版本兼容性校验（容错加载）

  • 属性有效性检查：载入用户已有的配置文件时，系统需对其包含的样式属性字段进行版本兼容性校验。
  • 容错应用与废弃属性提示：若检测到配置文件中包含当前版本已不再支持或已废弃的属性字段：
    1. 正常应用受支持属性：系统仍继续加载该配置文件，并将其中当前版本依然支持的属性配置正常应用到页面样式中。
    2. 弹窗提示废弃项：弹出提示窗口，清晰列出所有已不被当前版本支持的失效属性字段，由用户自行确认并选择后续操作。
